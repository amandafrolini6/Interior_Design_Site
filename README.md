Site Institucional – Escritório de Design de Interiores (Persona)
Este projeto apresenta o site institucional de um escritório fictício de design de interiores de alto padrão em São Paulo, inspirado na persona Studio Aura.
Criado durante a Imersão Dev do Futuro, promovida pela Dev em Dobro.
🚀 Tecnologias utilizadas
HTML
CSS
JavaScript
📌 Funcionalidades
Página inicial com identidade visual da persona
Sessão de serviços
Galeria de projetos
Sobre a persona fictícia
Página de contato
Layout responsivo
🎯 Objetivo
Praticar fundamentos de desenvolvimento web, estruturação de layout, responsividade e organização de projetos front-end.
